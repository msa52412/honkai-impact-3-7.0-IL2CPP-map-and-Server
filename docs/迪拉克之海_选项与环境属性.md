## 一、如何识别"迪拉克之海"的数据

迪拉克之海与量子奇点共用 `OWEndless*` 表族，靠 **`Type` 字段**区分：

| 字段 | =2 | =3 | =5 |
|---|---|---|---|
| `OWEndlessGroup.Type` | **迪拉克之海** | 量子奇点 | （另一变体） |
| `OWEndlessBattleConfig.EndlessConfigType` | **迪拉克之海**（598 条） | 量子奇点（299 条） | — |
| `OWEndlessAreaScoreConfig.Type` | **迪拉克之海**（15 条） | 量子奇点（41 条） | — |
| `OWEndlessPlayerBaseReward.Type` | **迪拉克之海**（108 条） | 量子奇点（95 条） | — |
| `OWEndlessPlayerGroup.Type` | **迪拉克之海**（2 条） | 量子奇点（3 条） | 3 条 |

内部代号：`OWEndless`（Openworld Endless，Type=2）；枚举 `EndlessTypeOpenworld`。

## 八、读取方法

```python
import json, os
BASE = r"D:\Carol-start\data\runtimes\win\LeServer\Resources\ExcelOutputAsset"

# 文案表（英文）
en = json.load(open(r"D:\Carol-start\千乐铃音_7.0\KianaBH\Resources\TextMap\TextMapEN.json", encoding="utf-8"))
tm = {r["value"]["hash"]: r["text"] for r in en if "value" in r}

# 环境属性
envs = json.load(open(os.path.join(BASE, "OWEndlessEnvironment.json"), encoding="utf-8"))
for e in envs:
    print(e["EnvironmentID"], tm.get(e["EnvironmentNameText"]["hash"]), tm.get(e["EnvironmentDescText"]["hash"]))

# 只取迪拉克之海（Type=2）
groups = [g for g in json.load(open(os.path.join(BASE, "OWEndlessGroup.json"), encoding="utf-8")) if g["Type"] == 2]
```
