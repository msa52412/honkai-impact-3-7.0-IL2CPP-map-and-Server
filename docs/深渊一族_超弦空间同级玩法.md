# 超弦空间（UltraEndless / 深渊 Abyss）同级别玩法

> 只读勘察。数据源：`LeServer\Resources\ExcelOutputAsset\`（1660 JSON）+ `Common.dll` + `TextMapEN.json`（英文文案，用于解析 hash）。
> 本次未修改任何文件。

---

## 一、最精确答案：与超弦空间"同一功能组"的玩法

全局入口表 **`WorldMap.json`** 的 `FeatureType` 字段决定入口归属。**超弦空间与下列玩法同属 `FeatureType = 18`**：

| EntryTitle | 中文 | 解锁等级 | FeatureType |
|---|---|---|---|
| **Superstring Dimension** | **超弦空间** | Lv.81 | **18** |
| Dirac Sea | 迪拉克之海 | Lv.25 | **18** |
| Q-Manifold | 量子流形 | Lv.25 | **18** |

> 即：**迪拉克之海、量子流形 是超弦空间的直接同级（同组轮换）玩法**。
> 文案佐证："Clear 10 floors of **Q-Manifold** or 4 stages of **Superstring Dimension**." —— 二者是每周任务的并列选项。

## 二、深渊一族（Endless 家族）全集

`Common.dll` 内 `EndlessType` 枚举共 7 值，即"深渊"体系的所有形态：

| EndlessType | 玩法（英文名） | 中文 | 内部表前缀 | 解锁 |
|---|---|---|---|---|
| `EndlessTypeNormal` | Infinity Abyss | 无限深渊 | （无独立表，基础深渊） | Lv.25 |
| `EndlessTypeOpenworld` | Dirac Sea | 迪拉克之海 | `OWEndless*`（Type=2） | Lv.25 |
| `EndlessTypeQuantum` | Q-Singularis | 量子奇点 | `OWEndless*`（Type=3）/ `QTEndless*` | Lv.25 |
| `EndlessTypeGreedy` | Q-Manifold | 量子流形 | `GreedyEndless*` | Lv.25 |
| `EndlessTypeUltra` | **Superstring Dimension** | **超弦空间** | `UltraEndless*` | Lv.81 |
| `EndlessTypeFront` | Blockade: Frontline | 封锁地带·前线 | `FrontEndless*` | 活动 |
| `EndlessTypeNone` | — | 无 | — | — |

**组别/段位证据**（`OWEndlessGroup.json` 的 `Type` 字段）：
- `Type=2` → 组名 `Dirac Sea: Forbidden / Sinful / Agony / Red Lotus / Myriad`
- `Type=3` → 组名 `QS: Forbidden / Sinful / Agony / Redlotus / Myriad`（QS = Q-Singularis）
- `GreedyEndlessGroup.json` → 组名 `Q-Manifold: Sinful / Agony / Redlotus`

## 三、终局玩法全景（WorldMap `FeatureType` 分组）

| FeatureType | 玩法 | 中文 | 说明 |
|---|---|---|---|
| 3 | Infinity Abyss | 无限深渊 | 深渊（基础） |
| **18** | **Dirac Sea / Superstring Dimension / Q-Manifold** | **迪拉克之海 / 超弦空间 / 量子流形** | **深渊核心组（同级）** |
| 108 | Q-Singularis | 量子奇点 | 深渊（独立入口） |
| 5 | Memorial Arena | 记忆战场 | 另一终局支柱（ExBoss） |
| 27 | Elysian Realm | 往世乐土 | 另一终局支柱（GodWar） |
| 109 | Universal Mirage | 万象虚境 | |
| 105 | Path of Apotheosis | 成神之路 | |
| 100 | Deep Archives / Character Trials | 深层档案 / 角色试炼 | |

> 结论：**严格同级 = 迪拉克之海、量子流形**（同 FeatureType=18）；
> **深渊体系同级 = 再加 无限深渊、量子奇点**；
> **终局玩法同级（不同机制）= 记忆战场、往世乐土**。

## 五、判断依据

1. `Common.dll` 字符串：`EndlessTypeNormal/Front/Greedy/Quantum/Openworld/Ultra`、`StageFrontEndless`、`StageGreedyEndless`、`StageQuantumEndless`、`CmdUltraEndless*`、`CmdGreedyEndless*`、`CmdFrontEndless*`、`CmdOpenworldEndless*`。
2. `WorldMap.json` 的 `FeatureType`：超弦空间 / 迪拉克之海 / 量子流形 同为 18。
3. `OWEndlessGroup.json` 的 `Type`：2=Dirac Sea、3=Q-Singularis；`GreedyEndlessGroup.json` 组名含 Q-Manifold。
4. `TextMapEN.json` 文案：Superstring Dimension / Dirac Sea / Q-Singularis / Q-Manifold / Infinity Abyss / Memorial Arena 均为独立玩法名。
