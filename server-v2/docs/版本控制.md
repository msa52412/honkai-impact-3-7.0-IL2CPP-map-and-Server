# 版本控制与回退

本目录（`server-v2`）已纳入 git，用于替代手工备份还原。

## 仓库范围

| 纳入 | 说明 |
|---|---|
| `Common/` `Server/` | 全部 C# 源码与 proto 定义 |
| `tools/` `docs/` | 工具脚本与文档 |
| `run/abyss_ow.json` `run/ultra_endless.json` `run/config.json` `run/appsettings.json` | 手工维护的调参文件 |

| 忽略 | 原因 |
|---|---|
| `**/bin/` `**/obj/` | 构建中间产物 |
| `run/*`（除上面 4 个 json） | `build.bat` 的 publish 输出，含 dll/pdb/Resources |
| `run/data/` | 数据库与账号存档 |
| `*.log` | 运行日志 |

`.gitattributes` 设了 `* -text`，关闭换行归一化。原因：`build.bat` 等批处理必须保持 CRLF
（cmd.exe 按字节偏移解析），一旦被转成 LF 就会坏。

## 常用命令

改之前先存一版：

```bash
cd /d D:\BH3\7.0\server-v2
git add -A
git commit -m "改了什么"
```

改坏了、还没提交 —— 全部丢弃：

```bash
git checkout -- .
```

已经提交了，想退回上一个可用版本：

```bash
git log --oneline          # 找到目标提交
git reset --hard <hash>
```

退回到「无限深渊实验全部回退后」的那个基线：

```bash
git reset --hard baseline-dirac
```

只想看自己改了什么：

```bash
git status
git diff
```

## 两个必须记住的坑

1. **git 只管源码，不管运行产物。** 还原源码后必须重新 publish 才会生效：

   ```bash
   build.bat
   ```

   然后重启 `run\Server.exe`。

2. **`run\abyss_ow.json` 是跟踪的，别用编辑器随手改完就忘。** 它是唯一进入版本控制的
   运行期配置；如果只是想临时试参数，改完记得 `git checkout -- run/abyss_ow.json` 复位。
